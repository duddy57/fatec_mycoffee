# MyCoffee

Aplicativo acadêmico para uma cafeteria, desenvolvido como parte da disciplina de **Programação para Dispositivos Móveis II**.

## Disciplina

- **Disciplina:** Programação para Dispositivos Móveis II
- **Professor:** Bruno Zolotareff dos Santos

## Estrutura do projeto

- `mobile/`: aplicativo mobile desenvolvido com Expo e React Native.
- `web/`: interface web desenvolvida com React e Vite.
- `api/`: API REST desenvolvida com NestJS e SQL Server.

## Tecnologias

- React Native e Expo
- React e Vite
- NestJS
- TypeScript
- SQL Server
